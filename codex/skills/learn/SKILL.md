description: Extract durable lessons from a corrected or difficult session and propose scoped Codex context, rule, skill or hook changes.
---

Use the actual correction, failed approach, verified fix and evidence. Separate
stable knowledge from task state. Propose minimal diffs and wait for approval.

Route broad preferences to ~/dev/dotfiles/codex/AGENTS.md; repository knowledge
to its native AGENTS.md; language rules to codex/rules/; domain/workflow guidance
to codex/skills/; enforceable boundaries to codex/hooks/ with regression checks;
machine restrictions to ignored codex/local/; open task state to a Codex handoff.

Codex has no Claude memory-writing tool or automatic per-agent memory directory.
Never update Claude contexts, settings, skills or hooks. Avoid duplicating lessons
across layers. Validate structure and runtime helpers. Behavioral evaluations
require their own approved run plan and model-call budget.
